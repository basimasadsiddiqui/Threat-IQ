A format reflow of `brag-output-linkedin/brag-plan.md`, not a new concept. Same
angle, same tone (`app-store`), same copy, same music and cue locks.

## What changes for square
Square has 1080px of height against vertical's 1920, so the vertical version's
accumulating column does not fit. Each beat **owns the frame and hands it on**
rather than stacking beneath the last. That costs the "everything visible at
once" poster moment and buys legible type at a size that survives a LinkedIn
feed thumbnail.

Consequences, decided deliberately:
- The score and the investigation's name share one frame, because the name
  reveal is the point of that beat and splitting them would break it.
- The two findings and the coverage line share one frame for the same reason.
- The four agent pills stay: they are the only evidence on screen that this is a
  graph rather than a single API call.
